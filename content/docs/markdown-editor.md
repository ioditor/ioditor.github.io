## Назначение

Три режима работают с содержимым одной Markdown-заметки.

| Режим | Для чего использовать |
|---|---|
| Visual | Писать и редактировать форматированный текст |
| Split | Одновременно видеть визуальное представление и исходную разметку; редактирование доступно в обеих панелях |
| Source | Работать непосредственно с Markdown и проверять точную разметку |

## Как использовать

Откройте Markdown-заметку и выберите нужное представление в верхней части редактора. В Visual встроенное руководство описывает меню Insert и ввод `/` для вставки блоков: таблиц, изображений, формул, Drawing и Mermaid.

## Пример

Создайте заголовок `# Моя заметка` в Source, затем переключитесь на Visual, чтобы увидеть его оформление. Split помогает сопоставить текст и результат.

## Ограничения

Visual поддерживает определённый набор Markdown и расширений. Для нестандартного синтаксиса используйте Source и проверяйте результат. Режимы редактирования Markdown не предназначены для изменения текста PDF или EPUB.
