Markdown — текстовый формат разметки. Для оформления используются обычные символы: например, решётка перед заголовком и звёздочки вокруг выделенного текста.

Эта страница описывает базовый синтаксис Markdown. Поддержка расширений и особенности отображения в iOditor будут описаны отдельно после проверки приложения.

## Заголовки

Количество решёток задаёт уровень заголовка. После решёток ставится пробел.

```markdown
# Название документа
## Раздел
### Подраздел
```

## Абзацы и выделение

Разделяйте абзацы пустой строкой. Для курсива используйте одну пару звёздочек, для полужирного текста — две.

```markdown
Первый абзац.

Второй абзац с *курсивом* и **полужирным текстом**.
```

## Списки

```markdown
- Первый пункт
- Второй пункт

1. Первый шаг
2. Второй шаг
```

## Ссылки

Текст ссылки заключают в квадратные скобки, а адрес — в круглые.

```markdown
[Название страницы](https://example.com/)
```

Адрес в примере демонстрирует синтаксис ссылки.

## Цитаты

```markdown
> Текст цитаты.
```

## Код

Короткий фрагмент кода обрамляют обратными кавычками: `` `имя_файла.md` ``.

Для блока кода используйте три обратные кавычки на отдельной строке до и после фрагмента:

````markdown
```text
Текст или код без форматирования.
```
````
