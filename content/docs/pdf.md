## Назначение

PDF открывается для чтения. Подтверждены переход по страницам, масштабирование, Fit Width, поиск, выделение текста и захват области страницы.

## Цитаты и выделения

Выделенный текст можно скопировать, перенести через Copy to Note в открытую заметку или отметить жёлтым, зелёным либо розовым цветом. Copy to Note добавляет текст и компактную ссылку Open source для возврата к источнику.

Панель Sources группирует сохранённые ссылки и выделения PDF/EPUB. Записи PDF-выделений сохраняются в каталоге данных приложения и не меняют исходный PDF. При переносе одного PDF на другой компьютер они не обязаны переноситься вместе с ним.

## Изображения

Capture region выделяет прямоугольную область страницы. По исходникам доступны копирование изображения, сохранение изображения и перенос в заметку. Для Thought Map предусмотрен перенос захваченной области на карту.

## Ограничения и неподтверждённое

Поиск и выделение текста требуют текстового слоя. Для сканов без него подтверждён просмотр, но распознавание OCR не подтверждено.

Под «аннотациями» здесь понимаются цветные выделения и заметки с источниками. Редактирование текста PDF, произвольные комментарии внутри PDF и экспорт выделений в стандартные PDF-аннотации пока не подтверждены.
