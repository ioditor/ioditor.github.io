## Поиск в заметке

В активной Markdown-заметке подтверждены поиск текста, переход между совпадениями, замена текущего совпадения и замена всех совпадений. Для поиска предусмотрен Ctrl+F. Перед заменой всех совпадений проверьте запрос и текст замены.

## Поиск в источниках

PDF имеет собственный текстовый поиск; для сканов нужен текстовый слой. Встроенное руководство также описывает отдельный поиск в EPUB.

Graph ищет документы по имени файла, относительному пути и заголовку H1. Он не ищет по всему тексту заметок.

## Поиск на сайте

Значок поиска в навигации этого сайта ищет по документации через FlexSearch. Это отдельная функция сайта.

## Что ещё нужно проверить

Полнотекстовый поиск по содержимому всей рабочей папки и OCR-поиск по изображениям не подтверждены этим обзором.
