Ниже перечислены возможности, подтверждённые по локальным исходникам и встроенному руководству MD Editor 0.3.20. Доступность редактирования зависит от состояния лицензии; условия публичного дистрибутива пока не подтверждены.

| Функция | Подтверждённое назначение |
|---|---|
| Markdown | Visual — форматированный редактор, Source — исходная разметка, Split — оба редактора рядом |
| Файлы и вкладки | Работа с локальной папкой, открытые документы во вкладках, автосохранение заметок и восстановление сессии |
| PDF | Чтение, поиск по текстовому слою, цветные выделения, перенос цитат и снимков в заметки |
| Аннотации | Выделения текста и ссылки на источник; отдельный редактор комментариев внутри PDF не подтверждён |
| Формулы | Строчные и блочные выражения LaTeX, визуальный ввод и просмотр исходника |
| Рисунки | Сетка, геометрические элементы, редактируемый SVG, растровые ориентиры PNG/JPEG |
| Thought Map | Встроенный плагин для ручных блоков, именованных связей и ссылок на источники |
| Поиск | Поиск и замена в активной заметке; отдельный поиск в PDF и Graph |
| Импорт и экспорт | Импорт Markdown/PDF/EPUB/Word, преобразование Word в Markdown; экспорт заметок в PDF и DOCX |
| Печать | Системный диалог печати для Markdown и PDF |
| Локальный чат | Ollama на локальном адресе, выбранный контекст и подтверждение предложенных правок |

Подробности доступны в [оглавлении]({{< relref "/docs" >}}). О пределах проверки читайте на странице [«Что проверено»]({{< relref "/docs/verification" >}}).
