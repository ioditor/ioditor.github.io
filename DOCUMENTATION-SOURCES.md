# Основа документации v0.3

Редакторский реестр, 11 октября 2026 года.
Проверены локальные материалы MD Editor 0.3.20. Они не включены в сайт.
Пути ниже относятся к приложению и нужны только для повторной сверки.

| Страница | Основа утверждений |
|---|---|
| Markdown, поиск, импорт/экспорт | src/renderer/src/App.tsx и src/renderer/src/help/user-guide.md |
| Файлы и вкладки, сессия | Встроенное user-guide.md, Getting Started и Files, Tabs, and Session |
| PDF и аннотации | components/PdfViewer.tsx, src/shared/highlights.ts, src/main/index.ts (pdf:highlights), встроенное руководство |
| Формулы | components/MathBlockEditor.tsx: inline/display, LaTeX, палитра, предпросмотр |
| Рисунки | DRAWING_GUIDE.md, включая дополнение 0.3.20; встроенное руководство |
| Thought | Встроенное user-guide.md, Thought Mode; хранение и ручное построение |
| Локальный чат | components/AIChat.tsx, src/main/ollama.ts: контекст, предложения правок, локальный HTTP |

Степень подтверждения: чтение кода и материалов без запуска приложения.
Некоторые старые пункты встроенного руководства описывают прежнее расположение элементов.
Скриншоты и полный маршрут по текущим командам требуют проверки установленной сборки.

Не заявлены OCR, стандартный экспорт PDF-аннотаций, глобальный поиск по содержимому,
облачный чат, LM Studio, автоматическая карта Thought и полная совместимость Word/LaTeX.
Публичные условия лицензирования и требования к дистрибутиву оставлены на последующую сверку.
